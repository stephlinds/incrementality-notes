# Incrementality Notes

Essays with runnable code on one question: does this action cause the outcome, or does it only predict it?

Most targeting scores, intent signals, and attribution dashboards answer "who is likely to convert." The question a budget depends on is different: "which action creates conversions that would not have happened anyway." Each piece here takes one place where those two questions get confused, and shows the difference with code.

## Ground rules

- **Every number comes from code in this repo.** If a figure in a piece cannot be regenerated by running the code next to it, it does not ship.
- **Synthetic data with planted ground truth.** The examples use generated data where the true treatment effect of every account is known. That is the only way to check whether a method recovers the truth. It also means no real customer or client data is used anywhere.
- **Oracle results are upper bounds.** When a piece uses the planted truth to show what perfect targeting would do, it is labelled as a benchmark, not an achievable result.
- **Limits are stated where the number appears.** Each result says which assumptions it rests on.

## Running the code

Each piece folder is self-contained. From inside a piece folder:

```bash
pip install -r ../requirements.txt
python src/generate_synthetic_crm.py --summary
jupyter nbconvert --to notebook --execute --inplace notebooks/sure_things_decomposition.ipynb
```

The generator is seeded, so the data and every figure reproduce exactly.
